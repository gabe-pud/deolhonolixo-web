# Front-End Web | De Olho no Lixo
- React + Tailwind Css + Vite

Após clonar o repositório e abrir no vscode, rode no terminal:

`npm run dev`

____________________________________________________________________________________________________
Os protótipos do sistema foram desenvolvidos para representar visualmente o funcionamento da plataforma antes da implementação completa das funcionalidades. Essa etapa permitiu validar a disposição dos elementos, os fluxos de navegação e a experiência geral do usuário.
O protótipo destinado ao cidadão apresenta uma tela principal contendo:
- Um mapa interativo com a localização do caminhão de coleta em tempo real;
- Um contador com o tempo estimado para chegada da coleta no bairro;
- Informações sobre a próxima coleta programada;
- Histórico das últimas coletas realizadas;
- Área de suporte e acesso ao aplicativo mobile.
- Já o protótipo administrativo possui um painel de controle voltado ao gerenciamento da frota, contendo:
- Cadastro de caminhões;
- Visualização em tempo real dos veículos registrados;
- Consulta de rotas e históricos de deslocamento;
- Ferramentas de pesquisa e monitoramento operacional.
- A navegação do sistema foi estruturada de maneira objetiva, utilizando menus simples e acessíveis. As funcionalidades principais permanecem visíveis ao usuário, reduzindo o número de interações necessárias para acessar informações importantes.
- Os protótipos também auxiliaram na validação da integração entre os componentes do sistema, especialmente a comunicação entre os mapas georreferenciados, os dados transmitidos pelos dispositivos IoT e a interface apresentada ao usuário final.
